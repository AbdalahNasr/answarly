# Draw.io Studio Regression Checklist

Run this checklist after each studio extraction:

- Add a shape from the library and draw it on the canvas.
- Move a shape and verify selection state updates.
- Change fill, stroke, and text properties and apply each change.
- Save the diagram through the owning form or page.
- Reload the diagram and confirm the shapes and page state remain.
- Export the diagram and verify the exported result is available.
